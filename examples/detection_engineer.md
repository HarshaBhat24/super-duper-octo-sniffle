# Reference Notes

Detection Engineering resumes should communicate the ability to

- Build detection systems
- Automate security workflows
- Integrate threat intelligence
- Develop reusable security tooling
- Engineer detection logic

The resume should read like that of an engineer building detection capabilities rather than a software developer building web applications.

Security concepts should always take precedence over implementation technologies.
