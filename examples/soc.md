# Reference Notes

SOC resumes should communicate the ability to

- Analyze security events
- Understand threat indicators
- Investigate suspicious activity
- Build and automate detection workflows
- Work effectively in Linux environments
- Apply networking fundamentals to security problems

Avoid making the resume appear like a software developer profile.

Security concepts should always be introduced before implementation details.
