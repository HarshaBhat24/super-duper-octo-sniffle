---

# Naming Convention

Base name: `outputs/YYYY-MM-DD_company_role`

Deliverables per application:
- `outputs/YYYY-MM-DD_company_role.html` (Standalone print-ready HTML matching reference PDF layout generated by the LLM)
- `outputs/YYYY-MM-DD_company_role.pdf` (Headless Chromium 1-page PDF export via `engine/export_pdf.py`)

Examples:
- `outputs/2026-10-21_google_appsec.html`
- `outputs/2026-10-21_google_appsec.pdf`

Keep the role name lowercase with underscores. Keep the company name lowercase.

---

# Notes

- The LLM generates the print-ready HTML resume directly, saving AI tokens.
- ATS Analysis, Competing Candidate Benchmarking, Priority Gap Strategy, and Company Intelligence are evaluated internally by the LLM during generation to shape the resume, but are omitted from text output to conserve tokens.
- If a resume is revised before sending, append `_v2`, `_v3` to the base filename.
